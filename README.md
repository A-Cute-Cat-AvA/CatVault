# CatVault
    **CatVault** 是一款纯本地、开源、零网络依赖的轻量级密码管理器。基于 Python构建，专为追求极致安全与便携的用户设计。绝对开源，保证你的密码不会被上传。你的所有密码都将被高强度加密，并可以随身存储在 U 盘中，真正实现“数据在自己手里，密码只属于自己”。

    ✨ **核心特性**

    🔒 **军工级安全**：采用 Argon2id 算法生成强密钥，结合 AES-256-GCM 认证加密算法，即使 U 盘丢失，捡到者也无法破解你的密码。

    💾 **极致便携**：无需安装，无需数据库。

    📝 **轻量纯粹**：不使用数据库，直接采用“内存字典 + 加密 JSON”的设计，体积小巧，读写极速。

    🛡️ **安全机制说明**

    **主密码绝不落地**：每次加解密都在内存中完成，绝不写入任何文件。

    **随机盐与 Nonce**：每次保存都生成全新的随机盐和 Nonce，防止重放攻击，确保相同密码每次加密结果都不同。

    **数据完整性校验**：GCM 模式内置认证标签，哪怕加密文件被篡改一个字节，解密也会直接失败。

    ⚠️ **重要警告**
    主密码是解锁数据的**唯一凭证**。一旦遗忘，神仙难救，请务必**牢记并定期备份 U 盘中的加密文件**！

# CatVault 云端备份仓库

    这个仓库是 **CatVault 密码管理器** 的云端备份存储空间。

    它利用 Gitee 的免费 API，将你**已经加密**的密码文件（`.dat`）上传到这里。
    服务器只负责存储密文，**没有任何人能解密**，包括 Gitee 和你自己（除非你有主密码）。

    ---

    ## 🚀 如何开启云端备份

    ### 第一步：创建你自己的 Gitee 仓库

    1. 登录 [Gitee](https://gitee.com)，点击右上角 `+` → `新建仓库`。
    2. **仓库名**：随便起，比如 `my-catvault-backup`。
    3. **可见性**：建议选 **私有**（心理上更安心）。
    4. **不要勾选** "初始化仓库"（保持空仓库）。
    5. 点击 `创建`。

    ### 第二步：生成私人令牌

    1. 打开 [Gitee 私人令牌设置页](https://gitee.com/profile/personal_access_tokens)。
    2. 点击 `生成新令牌`。
    3. 描述填写：`CatVault 备份`。
    4. 勾选权限：**只需勾选 `projects`**。
    5. 点击 `提交`，复制生成的那串 Token（只显示一次，请立即保存）。

    ### 第三步：配置 CatVault

    打开 CatVault 目录下的 `Options.op` 文件，写入以下内容：

    ```json
    {
    "cloud": true,
    "last_backup": "",
    "gitee_token": "你刚才生成的Token",
    "gitee_owner": "你的Gitee用户名",
    "gitee_repo": "你的仓库名"
    }

    ❓ 常见问题
        Q：我的密码库很大，会不会存不下？
        A：不会。.dat 文件非常小（通常几十 KB），Gitee 免费仓库容量完全够用。

        Q：Gitee 仓库是公开的，别人能看到我的密码吗？
        A：不能。文件在上传前已经用你的主密码加密了，别人看到的只是一堆乱码。

        Q：我换了电脑，怎么恢复密码库？
        A：把 Options.op 和 CatVault 程序复制到新电脑，执行 cloud restore gitee 即可。

        Q：如果我不小心把 Gitee Token 泄露了怎么办？
        A：立即登录 Gitee，在私人令牌页面删除旧令牌，重新生成一个新的，并更新 Options.op。
